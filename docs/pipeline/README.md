# Архитектура пайплайна обработки LiDAR для мониторинга энергоинфраструктуры

Описание сквозного open-source решения для обработки данных воздушного лазерного сканирования (ВЛС) и аэрофотосъемки (АФС) с применением машинного обучения. Разработано для автоматизации мониторинга воздушных линий электропередачи (ВЛ) 110-220 кВ.

---

## Структура пайплайна

Пайплайн состоит из четырех последовательных этапов:

### Этап 1. Геодезическая и фотограмметрическая обработка

**Вход:** RINEX-файлы, RTK/POS файлы, аэрофотоснимки (JPEG), метаданные

**Инструменты:** RTKLIB, OpenDroneMap (ODM)

**Процесс:**
- ГНСС-обработка (PPK/PPP) через RTKLIB
- Коррекция "левер-арм" (смещение антенна → камера)
- Фотограмметрическая обработка в ODM

**Результат:** Ортофотоплан, DSM/DTM, плотное облако точек (LAS/LAZ)

---

### Этап 2. Подготовка LiDAR-данных для ML

**Вход:** Облака точек с Этапа 1 + данные лазерного сканирования

**Инструменты:** PDAL, LASpy

**Процесс:**
- Объединение и конвертация LAS/LAZ
- Окрашивание из ортофотоплана (добавление RGB)
- Классификация земли (SMRF)
- Извлечение признаков: HAG, Linearity, Planarity, Verticality

**Результат:** Облако точек с признаками, готовое для модели

---

### Этап 3. Семантическая сегментация облака точек

**Вход:** Подготовленное облако точек (12 признаков)

**Инструменты:** PyTorch, PyTorch Geometric, Myria3D

**Модель:** RandLA-Net

**Процесс:**
- Разбиение на чанки (50 м, перекрытие 75%)
- Инференс модели → классификация каждой точки

**Результат:** 8 классов: vegetation, building, road, wire, tower, pipeline, temp+perm, fences

**Метрики (на 12-й эпохе):**
- mIoU: 0.676
- Прогноз к финалу: 0.75-0.80

---

### Этап 4. Постобработка, геоанализ и публикация

**Вход:** Классифицированное облако точек

**Инструменты:** PostGIS, GeoServer, Python (Shapely, GeoPandas)

**Процесс:**
- Векторизация проводов, опор, растительности
- Расчет габаритов, охранных зон, угрожающих деревьев
- Загрузка в PostGIS и публикация через GeoServer (WMS, WFS, MVT)

**Результат:** Векторные слои с дефектами для отчетности и визуализации

## Технологический стек

| Компонент | Технологии |

## Ключевые инновации

1. **Joint Training** — общий энкодер + 2 головы (5 классов + 2 класса), улучшил IoU редких классов на 88-93%
2. **Staged Training** — сначала Focal Loss (высокий Recall), затем CrossEntropy (повышение Precision)
3. **Smart Sampling** — стратифицированная выборка с приоритетом по линейности для сохранения проводов
4. **Вокселизация Ground** — снижение плотности земли с 42% до 24%, ускорение обучения
