### 🚀 Избранные проекты

> *Более полное портфолио доступно по ссылкам в шапке профиля.*

#### **🛰️ Open-Source пайплайн анализа ЛЭП с ИИ (НИОКР для ПАО «Россети»)**
*Роль:* Архитектор и ведущий разработчик пайплайна.  
*Задача:* Создать сквозное open-source решение для автоматического анализа воздушных линий электропередач по данным LiDAR с БПЛА.
*Решение и стек:*
*   Спроектировал микросервисную архитектуру обработки данных.
*   Разработал полный конвейер: от приёма сырых данных LAS/LAZ (`PDAL`, `LASpy`) до сегментации облаков точек и ML-классификации объектов (опоры, провода, здания и остальная инфраструктура) с помощью `scikit-learn`/`TensorFlow`.
*   Полностью контейнеризовал (`Docker`) пайплайн для воспроизводимости и развертывания в WSL-среде.
*Результат:* Готовый инструмент для автоматического выявления сближений и дефектов на ВЛ, заменяющий дорогостоящие коммерческие аналоги.

#### **🏙️ Цифровой двойник 4D города Иннополис**
*Роль:* Тимлид ГИС-направления. Проект успешно сдан на государственной приемке (2025 г.).
*Задача:* Создать централизованную платформу геоданных и визуализации для цифрового двойника.
*Решение и стек:*
*   **Архитектура данных:** спроектировал и развернул централизованное хранилище на `PostgreSQL/PostGIS`. Консолидировал векторные данные (CAD, Shapefile), ортофотопланы, 3D-модели (`CityJSON`).
*   **ETL и автоматизация:** разработал комплекс ETL-конвейеров в `FME` и на `Python` (`GDAL`, `Pandas`) для валидации и загрузки данных.
*   **Публикация и визуализация:** настроил `GeoServer` (OGC WMS/WFS), реализовал интерактивную веб-карту с 3D на `MapLibre GL JS`.
*Результат:* Единая точка доступа к актуальным пространственным данным города для анализа и принятия решений.

#### **⛽ Промышленный пайплайн обработки данных БПЛА для ООО «Газпром ВНИИГАЗ»**
*Роль:* Разработчик решения.
*Задача:* Автоматизировать обработку данных БПЛА для мониторига объектов газовой инфраструктуры с высокой точностью.
*Решение и стек:*
*   Создал сквозной Docker-пайплайн, объединяющий геодезическую обработку (`RTKLIB` с PPK/PPP) и фотограмметрию (`OpenDroneMap`).
*   Обеспечил планово-высотную точность конечных продуктов (ортофотопланы, ЦМР) на уровне **2-5 см**.
*Результат:* Внедрённое экономичное open-source решение, эффективно заменяющее коммерческие пакеты (Pix4D, Agisoft) в промышленной эксплуатации.
